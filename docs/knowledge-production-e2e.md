# Knowledge — production E2E checklist

The steps that have to be walked, in order, the first time this runs
against real infrastructure. Everything before this point was proven
against local PostgreSQL, a real HNSW index, and deterministic fakes;
nothing here has ever touched a real provider.

Status values used below:

- **READY** — the code is in place and verified as far as it can be
  without the real thing
- **BLOCKED** — waiting on a credential, a decision, or an action only
  an operator can take
- **NOT TESTED** — reachable, but never exercised against real infra

No value in this file is invented. Where a decision is outstanding it
says so rather than suggesting one.

## Pipeline

| # | Item | Status | What proves it |
|---|---|---|---|
| 8 | Embedding probe | **NOT TESTED** | `GET /api/knowledge/indexing` must report `semanticSearch.enabled: true` and the configured model. **No embedding has ever been generated by a real provider.** The client is proven to *ask* for 768 and *refuse* any other width; that Gemini *returns* 768 for the chosen model is unproven. |

## Order of operations

1. Set 1–5. Deploy.
2. Check 6 and 7 read-only. Install the extension only if missing.
3. `GET /api/knowledge/indexing` — expect `semanticSearch.enabled: true`
   and the model you configured. If it says `provider_not_configured`,
   one of items 3 or 4 did not reach the runtime.
4. Save **one** item and let the tick index it (item 9). Confirm the
   embedding row before going further — this is the first real proof
   that the chosen model returns 768.
5. Ask a lexical question, then a paraphrased one (items 10–12).
6. Only then run the backfill: `GET` for the dry run, read the
   estimated embedding calls, `POST` when the number is acceptable.
7. Smoke test (item 17).

## Stop conditions

Stop and report rather than working around:

- The embedding probe returns a width other than 768. The pipeline
  refuses it by design; the fix is the model choice, not the code.
- pgvector cannot be installed on Neon. There is no fallback and none
  should be built — the architecture decision was explicit.
- The backfill dry run reports a number of embedding calls larger than
  expected. It costs real money per chunk.
- `unresolvedCitationIds` is non-empty on a real answer. The UI already
  marks it unverified; a systematic occurrence means the prompt or the
  context assembly needs work before this is trusted.
